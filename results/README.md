# Results index

All files are generated by `scripts/run_all.command`. The main numbers in the project README come from `evaluate.py`.

| File(s) | Produced by | What it is |
|---|---|---|
| `final_results.md` | evaluate.py | **Main results**: DS2 + SVDB tables and the per-patient error table |
| `ds2_{lr,cnn,ensemble}.json` / `_confusion.png` | evaluate.py | Final models on DS2 (22 unseen MIT-BIH patients) |
| `svdb_{lr,cnn,ensemble}.json` / `_confusion.png` | evaluate.py | Final models on SVDB (78 patients, second database) |
| `per_patient_ds2.json`, `per_patient_errors.png` | evaluate.py | Errors per DS2 patient |
| `ensemble.json` | evaluate.py | Ensemble weight and the validation scores used to choose it |
| `model_comparison.png` | scripts/compare_plot.py | Per-class sensitivity / +P chart |
| `detector.json` | detection.py | QRS detector sensitivity / +P, per record |
| `logistic_regression_detected.*` | detection.py | Fully automatic pipeline (detected R peaks) on DS2 |
| `cnn_seeds.json`, `cnn.json`, `cnn_history.json`, `cnn_training.png`, `cnn_confusion.png` | train.py | CNN training: per-seed DS2 scores and training curve |
| `logistic_regression.*`, `gradient_boosting.*` | baseline.py | Feature-only baselines trained on all DS1 patients (train + validation) |

Note: `logistic_regression.json` (baseline.py, trained on all 22 DS1 patients) and `ds2_lr.json` (evaluate.py, trained on the
18 training patients so the 4 validation patients stay unseen for choosing the ensemble weight) differ slightly for that reason.
